한 줄 요약

이 앱은 인터넷 권한(INTERNET)이 없습니다. 기술적으로 어떤 데이터도 기기 밖으로 보낼 수 없습니다. 개발자를 포함해 누구도 사용자의 기록(현장·토량·장비 조합·임대료·설정)을 볼 수 없습니다.

광고도, 인앱 결제도 없습니다.

수집하는 정보

아무것도 수집하지 않습니다. 계정도, 로그인도, 광고 SDK 도, 분석 도구도 없습니다.

권한

런타임 권한을 하나도 요청하지 않습니다.

  • 백업 파일은 문서 선택기로 다룹니다 — 사용자가 고른 파일 하나만 읽고 씁니다
  • 장비 작업량 계산서 PDF 는 공유 창으로 사용자가 고른 앱에만 보냅니다
  • 위치(GPS)를 쓰지 않습니다 — 운반 거리·토량은 사용자가 직접 넣습니다
안드로이드 기본 라이브러리(androidx.core)가 이 앱 전용 내부 권한 하나 (…DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION)를 자동으로 추가합니다. 앱 내부 신호가 다른 앱으로 새지 않게 막는 장치이며, 사용자에게 묻는 권한이 아닙니다.

요청하지 않는 권한 — 인터넷, 위치, 카메라, 연락처, 저장소 전체, 마이크, 알림.

제3자 제공·공유

없습니다.

기록과 파일

현장(토량·흙·장비 사양·임대료·목표 일수)·고친 기준값·계산기 입력은 기기 안에만 저장됩니다. 장비 작업량 계산서 PDF 는 사용자가 「보내기」로 고른 앱으로만 나갑니다. 백업 파일은 사용자가 고른 위치에 저장되며, 어디로도 올라가지 않습니다.

앱을 삭제하면 앱 안의 기록(현장·기준값·설정)이 함께 삭제됩니다. 지우기 전에 남기고 싶으면 앱의 백업으로 파일 한 개로 빼낼 수 있습니다. 개발자는 사용자의 데이터를 갖고 있지 않으므로, 따로 삭제를 요청할 곳이 없습니다.
