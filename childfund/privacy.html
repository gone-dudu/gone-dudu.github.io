한 줄 요약

베베셈은 계정도 로그인도 서버도 없습니다. 고른 조건으로 지원금을 계산하는 일은 전부 이 기기 안에서 이루어지며, 입력한 내용은 기기 밖으로 나가지 않습니다.

이 앱은 정부 공식 앱이 아닙니다

베베셈은 개인이 만든 계산 도구입니다. 정부·공공기관이 만들거나 위탁한 앱이 아니며 그 어떤 기관과도 제휴 관계가 없습니다.

발표된 제도 내용을 바탕으로 금액을 계산해 볼 뿐, 신청을 대행하거나 지원 자격을 확정해 주지 않습니다. 실제 신청과 자격 확인은 복지로·정부24 등 공식 창구를 이용해 주세요.

계산에 쓰는 금액은 발표된 정부안 기준이며, 국회 심의 과정에서 달라질 수 있습니다.

수집하지 않는 것

  • 입력한 조건(출생 순위·거주지역 해당 여부·양육 방식·혼인 여부) — 기기 밖으로 전송하지 않습니다
  • 이름·이메일·전화번호·주소 등 신원 정보
  • 가족관계·출산 예정일 등 어떤 개인 기록도 요구하지 않습니다
  • 연락처·통화기록·문자
  • 사진·카메라·마이크
  • 위치 정보

베베셈은 자체 서버를 두지 않습니다. 앱이 직접 어딘가로 보내는 데이터가 없습니다.

수집하는 것

광고 식별자 — 광고 SDK

Google AdMob 이 앱 안 광고를 게재하며 광고 ID·App Set ID 를 사용합니다. 앱이 직접 수집하거나 보관하지 않으며, 기기 설정에서 광고 ID 를 초기화하거나 맞춤 광고를 끌 수 있습니다.

앱 이용 정보 · 진단 정보 — 광고 SDK

광고 노출·클릭 같은 상호작용과 오류·성능 진단 정보를 Google AdMob 이 수집합니다. 계산에 입력한 조건이나 계산 결과는 여기에 포함되지 않습니다.

기기 안에만 남는 것

아래 정보는 외부로 전송되지 않으며 앱을 삭제하면 함께 지워집니다.

  • 마지막으로 고른 계산 조건 — 다시 열었을 때 처음부터 고르지 않아도 되게 하기 위한 것입니다
  • 앱 실행 횟수

아동

앱은 아동을 주 대상으로 하지 않으며, 아동으로부터 의도적으로 정보를 수집하지 않습니다.

데이터 삭제 요청

베베셈은 계정이 없고 서버에 보관하는 이용자 데이터가 없으므로 따로 탈퇴 절차가 없습니다.

앱을 삭제하면 기기에 저장된 계산 조건과 실행 횟수가 함께 지워집니다. 앱을 지우지 않고 지우려면 기기 설정 > 애플리케이션 > 베베셈 > 저장공간 > 데이터 삭제 를 실행하면 모두 초기화됩니다.

광고 식별자의 사용을 멈추려면 기기 설정 > 개인정보 보호 > 광고 에서 광고 ID 를 삭제하거나 초기화할 수 있습니다.
