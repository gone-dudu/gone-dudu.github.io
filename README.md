# gone-dudu.github.io

`gone` 계정으로 게시하는 앱들의 **개인정보처리방침 호스팅**. GitHub Pages 로 서비스된다.

```
index.html              루트 — 의도적으로 비어 있다(아래 참고)
<앱slug>/privacy.html   앱마다 한 장
```

공개 URL = `https://gone-dudu.github.io/<앱slug>/privacy.html`
→ Play Console [앱 콘텐츠] · [스토어 등록정보] 의 개인정보처리방침 URL 에 그대로 넣는다.

## 규칙

1. **루트에 앱 목록을 두지 않는다.** `index.html` 은 빈 화면 + `noindex` 다.
   앱 A 의 정책 URL 을 본 사람이 루트로 올라가 앱 B 를 발견하는 경로를 만들지 않기 위한 것으로,
   이 저장소가 다른 계정·다른 저장소와 분리돼 있는 이유와 같다. 앱끼리도 서로 링크하지 않는다.
2. **앱 하나 = 폴더 하나.** 다른 앱 페이지를 고칠 일이 없게 파일을 섞지 않는다.
3. 문서 내용이 바뀌면 페이지 안의 **최종 수정일**을 같이 고친다. Play 심사가 이 날짜를 본다.
4. 앱이 실제로 하는 일과 문서가 어긋나면 정책 위반이다 — 권한·SDK·수집 항목을 바꿨으면
   같은 작업에서 이 페이지도 고친다.

앱 쪽 정본 문서는 `ideaapp` 저장소의 `docs/STORE.md` 에 있다.
