한 줄 요약

이 앱은 인터넷 권한(INTERNET)이 없습니다. 기술적으로 어떤 데이터도 기기 밖으로 보낼 수 없습니다. 개발자를 포함해 누구도 사용자의 악보·셋리스트·주석을 볼 수 없습니다.

광고도 없습니다.

수집하는 정보

아무것도 수집하지 않습니다. 계정도, 로그인도, 광고 SDK 도, 분석 도구도 없습니다.

권한

런타임 권한을 하나도 요청하지 않습니다.

  • PDF 악보와 백업 파일은 문서 선택기로 엽니다 — 사용자가 고른 파일 하나만 읽습니다
  • 사진은 사진 선택기로 고릅니다 — 갤러리 전체에 접근하지 않습니다
  • 촬영은 기기의 기본 카메라 앱이 합니다 — 이 앱은 카메라 권한을 갖지 않습니다
  • 블루투스 페이지 넘김 페달은 키보드로 연결됩니다 — 블루투스 권한이 필요 없습니다
안드로이드 기본 라이브러리(androidx.core)가 이 앱 전용 내부 권한 하나(…DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION)를 자동으로 추가합니다. 앱 내부 신호가 다른 앱으로 새지 않게 막는 장치이며, 사용자에게 묻는 권한이 아닙니다.

요청하지 않는 권한 — 인터넷, 카메라, 위치, 연락처, 저장소 전체, 블루투스, 마이크, 알림.

제3자 제공·공유

없습니다.

악보와 백업 파일

가져온 악보는 이 앱 안에 복사해 두고, 페이지 이미지로 만들어 기기에만 저장합니다. 백업(zip)은 사용자가 고른 위치에 파일로 저장되며, 어디로도 올라가지 않습니다. 사용자가 직접 그 파일을 옮기거나 공유할 때만 기기 밖으로 나갑니다.
