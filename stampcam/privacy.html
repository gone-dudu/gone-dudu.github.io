한 줄 요약

이 앱은 Google AdMob 광고를 표시합니다. 광고 SDK 가 수집하는 항목은 아래에 적었습니다. 그 외에 개발자가 따로 수집하는 정보는 없습니다.

수집하는 정보

개발자가 수집하는 정보: 없습니다.

광고를 위해 Google AdMob SDK 가 다음을 수집·공유할 수 있습니다:

  • 기기 또는 기타 ID(광고 ID · App Set ID)
  • 앱 상호작용 · 앱 성능 진단

용도는 광고, 분석, 사기 방지·보안입니다. 자세한 내용은 Google 의 광고 데이터 공개 문서와 개인정보처리방침(https://policies.google.com/privacy)을 따릅니다. Android 설정 › 개인정보 보호 › 광고에서 광고 ID 를 삭제하거나 맞춤설정을 끌 수 있습니다.

권한

  • CAMERA — 사진을 찍기 위해서만 씁니다
  • 위치(선택) — 주소 스탬프를 켰을 때만. 주소는 기기 안에서 만들어 사진에 글자로 박습니다. 사진 파일의 EXIF 에는 좌표가 남지 않고, 위치는 어디로도 전송되지 않습니다
  • INTERNET — 광고 표시용입니다
광고 SDK 는 위에 적은 것 외에 AD_ID·ACCESS_ADSERVICES_*·WAKE_LOCK·FOREGROUND_SERVICE 권한을 자동으로 추가합니다. 광고 전달과 측정을 위한 것이며, 개발자가 그 권한으로 따로 하는 일은 없습니다.

제3자 제공·공유

광고 SDK 외에는 없습니다. 사진은 기기의 갤러리에만 저장되며 전송되지 않습니다.
