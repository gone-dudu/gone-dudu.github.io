한 줄 요약

첫값은 계정도 로그인도 본인인증도 없습니다. 어떤 기관에도 조회하지 않고 이용자가 직접 입력한 내용으로만 계산합니다. 그 내용은 이 기기 안에만 남습니다.

이 앱이 하지 않는 것

  • 거래소에 연결하지 않습니다. API 키·로그인·계좌 연동이 없습니다
  • 세금을 신고하거나 대신 내지 않습니다. 신고는 이용자가 직접 합니다
  • 코인을 사고팔거나 추천하지 않습니다. 투자 권유가 아닙니다
  • 지갑 주소·거래소 계정·실명 정보를 받지 않습니다

앱의 계산은 비공식 참고용이며, 실제 과세 여부와 세액은 관계 법령과 과세 당국의 판단으로 정해집니다. 이 앱은 정부기관이나 거래소가 만든 앱이 아닙니다.

수집하지 않는 것

  • 입력한 코인 이름·매수/매도 날짜·수량·단가·수수료 — 기기 밖으로 전송하지 않습니다
  • 거래소 계정·지갑 주소·API 키
  • 실제 보유 자산·잔고
  • 이름·생년월일·주민등록번호 등 신원 정보
  • 연락처·사진·카메라·마이크
  • 위치 정보

첫값은 이용자 정보를 받는 서버를 두지 않습니다.

수집하는 것

광고 식별자 — 광고 SDK

Google AdMob 이 앱 안 광고를 게재하며 광고 ID·App Set ID 를 사용합니다. 앱이 직접 수집하거나 보관하지 않으며, 기기 설정에서 광고 ID 를 초기화하거나 맞춤 광고를 끌 수 있습니다.

앱 이용 정보 · 진단 정보 — 광고 SDK

광고 노출·클릭 같은 상호작용과 오류·성능 진단 정보를 Google AdMob 이 수집합니다. 이용자가 입력한 매수·매도 기록은 여기에 포함되지 않습니다.

기기 안에만 남는 것

아래 정보는 외부로 전송되지 않으며 앱을 삭제하면 함께 지워집니다.

  • 코인 이름 — 이용자가 직접 적는 글자입니다. 무엇을 적든 기기 밖으로 나가지 않습니다
  • 매수·매도 구분과 날짜, 수량, 단가, 수수료
  • 2026년 12월 31일 기준 시가(이용자가 직접 적은 값)
  • 실제 매수가를 모르는 코인인지 여부
  • 내려받은 기준표(아래)

기준 값은 어떻게 갱신되나

가상자산 과세는 2027년 1월 1일 시행이 예고된 제도입니다. 기본공제 250만원 · 세율 20%(지방세 별도) · 취득가액 기준일(2026-12-31)이 전부 법 개정이나 시행 연기로 바뀔 수 있는 값입니다. 그래서 앱은 하루 한 번 gone-dudu.github.io/cheotgap/tax.json 에서 최신 기준표를 받아옵니다.

이 요청은 표를 내려받기만 하며 이용자 정보를 함께 보내지 않습니다. 내려받기가 실패하면 앱에 들어 있는 값으로 그대로 동작합니다.

데이터 삭제 요청

첫값은 계정이 없고 서버에 보관하는 이용자 데이터가 없으므로 따로 탈퇴 절차가 없습니다.

앱을 삭제하면 기기에 저장된 내용과 설정이 함께 지워집니다. 앱을 지우지 않고 지우려면 기기 설정 > 애플리케이션 > 첫값 > 저장공간 > 데이터 삭제 를 실행하면 입력한 내용·기록이 모두 초기화됩니다.

광고 식별자의 사용을 멈추려면 기기 설정 > 개인정보 보호 > 광고 에서 광고 ID 를 삭제하거나 초기화할 수 있습니다.
