날기 개인정보처리방침

최종 수정일 2026-09-26

한 줄 요약

이 앱은 Google AdMob 광고를 표시합니다. 광고 SDK 가 수집하는 항목은 아래에 적었습니다. 그 외에 개발자가 따로 수집하는 정보는 없습니다.

일기는 이 기기 안에만 있습니다. 계정도 로그인도 서버도 없습니다. 개발자는 사용자가 쓴 일기를 볼 수 없습니다.

수집하는 정보

개발자가 수집하는 정보: 없습니다.

광고를 위해 Google AdMob SDK 가 다음을 수집·공유할 수 있습니다:

  • 기기 또는 기타 ID(광고 ID · App Set ID)
  • 앱 상호작용 · 앱 성능 진단

용도는 광고, 분석, 사기 방지·보안입니다. 자세한 내용은 Google 의 광고 데이터 공개 문서와 개인정보처리방침(https://policies.google.com/privacy)을 따릅니다. Android 설정 › 개인정보 보호 › 광고에서 광고 ID 를 삭제하거나 맞춤설정을 끌 수 있습니다.

🔴 광고 SDK 는 일기 본문에 접근하지 않습니다. 일기는 앱 전용 저장소에 있고 광고는 화면에 얹히는 별개의 구성요소입니다.

권한

  • INTERNET — 광고 표시용입니다. 일기와 사진은 이 경로로 전송되지 않습니다
광고 SDK 가 위에 적은 것 외에 AD_ID·ACCESS_ADSERVICES_*·ACCESS_NETWORK_STATE· WAKE_LOCK·FOREGROUND_SERVICE 권한을 자동으로 추가합니다. 광고 전달과 측정을 위한 것이며, 개발자가 그 권한으로 따로 하는 일은 없습니다.

요청하지 않는 권한 — 위치, 연락처, 저장소, 카메라, 알림. 일기에 넣는 사진은 안드로이드 사진 선택기로 고르므로 저장소 권한이 필요하지 않습니다.

제3자 제공·공유

광고 SDK 외에는 없습니다. 일기 본문과 사진은 전송되지 않습니다.

아동

이 앱은 만 13세 미만을 대상으로 하지 않습니다.

데이터 삭제

앱을 삭제하면 일기와 사진이 함께 삭제됩니다. 🔴 지우기 전에 반드시 내보내세요 — 앱의 [더보기 › 내보내기]가 일기와 사진을 zip 파일 한 개로 빼냅니다. 그 안의 entries.json 은 그냥 읽을 수 있는 글이라, 다른 앱으로 옮기고 싶어져도 붙잡지 않습니다.
